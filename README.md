## 🎯 目标

**让用户更简单地完成开发任务。**

---

## 📜 初衷

一个智能管理来控制几个分管理，而每个分管理又分别控制着多个子skill。以金字塔型的管理机制，当用户提出要求时，由智能管理综合调控，通过调用分管理，来实现最终调用需要调用的子skill帮助用户完成任务。

---

## 🏗️ 架构

```
Master(调度中枢) → VP(分管理) → Expert(子Skill)
     │
     ├── 技术VP → 前端/后端/移动/重构/性能/测试/执行
     ├── 产品VP → UIUX/文档
     └── 运营VP → DevOps/商业
```
